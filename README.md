# FightingFit - UFC Fight Analytics Dashboard

An end-to-end data analytics project that explores UFC fight data and builds insights into what drives victory inside the octagon.

---

## 📊 Project Overview
- **Goal:** Turn raw UFC fight data into an interactive analytical dashboard.
- **Technologies Used:**
  - Python (Pandas, MySQL Connector) – data cleaning & ETL
  - MySQL – relational database for structured storage
  - Tableau – interactive visualizations
  - Medium – documentation & sharing insights

## 🧩 Key Insights
- Reach is the strongest physical predictor of winning.
- Height matters only when paired with a reach advantage.
- Younger fighters have a slight edge.
- Positive takedown differential increases win probability.
- Underdogs in certain odds ranges are consistently undervalued.

---

## 🔗 How to Run This Project
1. **Python Scripts:**  
   - Clean and prepare data (`py/*.py`)  
   - Export data to CSV for Tableau

2. **Database:**  
   - Load CSVs into MySQL database using `py/load_data.py`

3. **Tableau:**  
   - Open `tableau/FightingFit.twb` to explore visualizations interactively.
